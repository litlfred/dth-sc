# dth-sc

The WHO **Digital transformation handbook for health supply chain architecture** (2024, ISBN 9789240101197), as an L2 Digital Transformation Handbook on [smart-ra](https://github.com/litlfred/smart-ra): narrative validated against the glossaries and linked to the DPI-H ArchiMate model.

- Working document: `folio/dth-sc/`, seeded from the L1 entry [`who-iris/library/9789240101197-eng`](https://github.com/litlfred/who-iris/tree/main/library/9789240101197-eng).
- Supply chain glossary: `glossary/dth-sc.glossary.json`.
- Plan: [`docs/workplan.md`](docs/workplan.md).
- Agent guidance: [`AGENTS.md`](AGENTS.md).

dth-pc (health product catalogue) and dth-sfp (substandard and falsified medical products) depend on this repository.

This is a fork of WorldHealthOrganization/dth-sc. Work happens here; nothing is pushed upstream without the owner's say-so.
