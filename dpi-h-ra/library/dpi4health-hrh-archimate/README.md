# DPI4Health — HRH ArchiMate model

`DPI4Health.archimate`: an Archi model named **HRH** (476 elements, 19 views —
health-workforce stakeholder, application-communication, layered and
sub-goal views). Uploaded to the repository root by Jose Costa Teixeira on
2025-12-18 and moved here on 2026-10-09.

**Source material, not a version of the reference architecture.** It predates
every model under `archimate/` and is not part of the `0.2.0` line, so it is
not named for a version and is not rendered: the ArchiMate report and the RA
mapper read only `archimate/<semver>/` (see `archimate/README.md`). Several of
its views ("1. Central Health Workforce Registry", "ALL HRH Conceptual View -
Stakeholder") reappear in `archimate/0.2.0/`.

To publish it, copy it into a version folder under `archimate/` — do not
edit it here.
